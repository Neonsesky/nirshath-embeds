How it works

One sheet. Four layers.

No backend, no database bill. The Google Sheet I already kept became the database, and everything was built on top of it.

Google Sheet

The source of truth. Every row: date, project, creative type, quantity. It worked before the app existed, and it still works without the app.

Apps Script API

Google Apps Script exposes the sheet as a JSON API. The app reads and writes through it, with a connection indicator so you always know the state.

GitHub Pages PWA

The front end is plain HTML, CSS and JS, deployed through GitHub Pages. Free hosting, versioned on GitHub, installable from the browser.

Any device

Desktop at the desk, PWA on the phone. Log a creative in seconds, pull a report in a click, from wherever the work happened.

What V2 added

Nine upgrades, one weekend each.

V2 shipped over six days in September. Each feature came from a real friction point in the week-to-week workflow.

REPORTS

Weekly & period reports

A dedicated Reports page with a date-range picker. Pick a week, pull the numbers, export the report as a PDF.

PDF

One-click PDF export

The report leaves the app as a clean PDF. No screenshots, no slide deck, no reformatting.

THEMES

8 presets + custom colours

Theme presets and a custom colour picker, including the navy-and-amber look this page borrows.

PWA

Installable app

Add to home screen, launch fullscreen. A web page that behaves like an installed app.

MOBILE

Bottom tab bar

Mobile-first navigation with thumb-reachable tabs: log, history, overview, reports.

SAFETY

CSV auto-backup

The app exports its own CSV backup so the data never depends on a single sheet.

DATA

Manage creative types

Creative types are editable in-app, so the taxonomy grows with the work instead of freezing at the first prompt.

CLEANUP

Re-tag suggestions

Flags inconsistently tagged entries and suggests fixes, keeping the metrics honest.

SIGNAL

Connection glow

A live status indicator shows when the app is connected to the sheet API. No silent failures.

The AI angle

AI didn't design the creatives.
It built the tool around them.

I'm a designer, not a developer. Claude Code closed that gap, and it changed the workflow, not the taste.

Built with 3 prompts.

V1 went from idea to working single-file app in three prompts and three GitHub pushes. The barrier between "this spreadsheet is annoying" and "there's an app for that" is gone for anyone who can describe what they want.

Reporting in one click.

Weekly output reporting is a Reports page, a date range and a PDF export. Reporting to leadership stopped being a screenshot scavenger hunt and became a step in the flow of work.

Output you can see.

Monthly, quarterly and yearly metrics give the design function visibility: 2,901 creatives across 432 projects, by type and volume. Design's output is finally as countable as any other team's.
