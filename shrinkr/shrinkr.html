02 · How it works

Drop. Set. Download.

Three steps, the same every time — settings changes re-run instantly, no re-upload.

01

Drop it in

Files, whole folder trees, or a ZIP — drag-and-drop, folder picker, and OneDrive files included.

02

Set the budget

A hard KB target (binary search finds the best quality that fits), a fixed quality, format and resize — scoped to a folder name if you like.

03

Download the ZIP

Identical folder structure and names come back. Save results straight back into the original folder in Chrome.

06Motion · Slow is premium
One ease

Everything uses cubic-bezier(.4,0,.2,1), 200–350 ms.

Hovers whisper

Brightness and border shifts only. Nothing bounces toward the cursor.

The aurora owns life

Hue drift ±55°, cursor trailing, breathing — all ambient motion is the background's.

Respect the switch

prefers-reduced-motion freezes the aurora and every transition. Always.

07Voice · Designer to designer
Say
  • “Nothing ever leaves your device.”
  • “Every banner under 120 KB — automatically.”
  • “Folder structure comes back exactly as it went in.”
  • Plain verbs, honest limits, trade-offs admitted out loud.
Never say
  • “Revolutionary AI-powered synergy.”
  • “Blazingly fast!!!”
  • Dark patterns: no guilt, no fake scarcity, no “wait!” modals.
  • Corporate distance — a designer built this, and writes like one.
